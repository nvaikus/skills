# UI on the tailnet (`ui --share`)

- Two shapes, tailnet only, never funnel. Service: `ui --share --service [NAME]` (default name `clockmaster`; the default on a tagged node) = `tailscale serve --service=svc:NAME --https=443 http://127.0.0.1:<ui port>` → `https://NAME.<MagicDNS suffix>/`. Port: `ui --share [HTTPS_PORT]` (default 8443; the default on an untagged node) = `tailscale serve --bg --https=<port> …` on the node's own name. Order: allow file, autostart on, gate probed on the running UI (403 without login, 200 for the owner), then the serve entry. A port that serves anything else is refused; other serve entries stay untouched.
- Allowed logins: `<data>/ui-allow.txt`, one per line. `share` adds this node's owner login (`tailscale status --json` Self user). Tagged node has no owner: `--allow <login>` needed only while the list is empty; the list is never wiped. Edits apply on the next request, no restart.
- Services (measured on 1.102): host must be tagged, tailscale ≥ 1.86; admin console → Services → Advertise → Define a Service `svc:NAME`, endpoint `tcp:443`; then the host needs approval (console) or an autoApprover. serve prints "approval from an admin is required" even when an autoApprover approves ~10-30 s later; truth = `tailscale status --json` Self.CapMap["service-host"] lists `svc:NAME` (undefined and unapproved look the same: absent; it lags advertise/clear by seconds both ways). Policy:
  `"autoApprovers": {"services": {"svc:clockmaster": ["tag:server"]}}`, `"grants": [{"src": ["autogroup:member"], "dst": ["svc:clockmaster"], "ip": ["tcp:443"]}]`
- `serve status --json` keeps services under `Services["svc:NAME"]` with their own `TCP`/`Web` (keyed `NAME.<suffix>:443`) next to node-level `TCP`/`Web`. `serve clear svc:NAME` drops it and un-advertises; clockmaster clears only a service whose every handler is this UI, else turns off just its port.
- The serving host cannot reach its own service VIP: test the URL from another device.
- Tailnet/node rename strands node-level entries keyed by the old DNS name: `serve --https=PORT off` → "handler does not exist". `ui`/`--unshare` flag them STALE; the only remedy is `sudo tailscale serve reset` (drops EVERY entry and service — re-add the others), never run automatically. Stale service entries go with `serve clear`.
- Gate (`src/web/gate.py`): a request with any forwarding/Tailscale header or a non-local Host needs exactly one allowed `Tailscale-User-Login`, else 403. Direct `127.0.0.1` requests (local browser, SSH tunnel) pass as before. Cross-site writes (Origin / Sec-Fetch-Site) get 403 everywhere.
- tailscale serve (measured on 1.102) drops client-sent `Tailscale-User-*` and `X-Forwarded-For` and sets its own. No login header for tagged devices and funnel traffic; a device shared in from another tailnet carries ITS owner's login → 403 unless listed.
- Other local users (Linux): `src/web/peer.py` reads the connecting socket's owner uid from `/proc/net/tcp{,6}` once per connection. Own uid passes; uid 0 passes (that is `tailscaled`, so the gate above still applies to proxied requests); any other uid or a failed lookup → 403 + a stderr line. macOS/Windows: no such check, any local user can reach the port.
- `serve` without operator rights says "Access denied": the command retries with `sudo -n`; else run once `sudo tailscale set --operator=$USER`.
- MagicDNS may be off on the serving machine itself: test there with `curl --resolve <name>:<port>:$(tailscale ip -4) https://<name>:<port>/`.
- `ui` and `ui --autostart` print a `tailnet:` line per entry (URL, service, allowed logins). `ui --unshare [PORT | --service [NAME]]` removes only entries pointing at this UI (all of them by default); the allow file stays.
- Second Linux user on the same host: own data dir and timers come for free; give it `ui --port <free port> --autostart on`, its login in its `ui-allow.txt`, and the serve entry from the operator user (`sudo tailscale serve --bg --https=<port> http://127.0.0.1:<ui port>`). For a user who reaches the host via node sharing, use a node port (shared nodes, not services, are what they see).
