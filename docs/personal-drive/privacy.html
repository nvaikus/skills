Privacy policy

Last updated: 2026-10-01

  • Personal Drive runs entirely on the user's own computer. It has no server and collects no data.
  • It accesses the user's Google Drive, Docs and Sheets only through Google APIs, with the scopes the user grants, and only to perform actions the user requests: mounting files locally, building a local search index, and reading or editing documents.
  • Google user data (files, document contents, tokens) is stored only on the user's computer and is never transmitted, sold or shared with the developer or any third party.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Users can revoke access at any time at myaccount.google.com/permissions and delete the local data by removing the tool's folders.
